# امنلاک | Amnlak

اپلیکیشن اندرویدی محاسبات املاک و ساخت‌وساز، با رابط فارسی و واحد تومان.

## امکانات نسخه 1.0.0
- محاسبه کمیسیون خرید و فروش، رهن کامل و اجاره با مالیات قابل تنظیم
- محاسبه سهم مالک و سازنده و سود پروژه مشارکت در ساخت
- برآورد زیربنای کل، میلگرد و بتن پروژه
- لوگوی اختصاصی و آماده توسعه

## ساخت APK
```bash
./gradlew assembleDebug
```
خروجی: `app/build/outputs/apk/debug/app-debug.apk`
